Отчёт по кейс-задаче №4
1. Постановка задачи
Разработать интерактивный калькулятор, который:
- содержит 2 инпута, 4 кнопки и окно для вывода результата;
- кнопки названы по операциям: «Сумма», «Разность», «Произведение», «Деление»;
- имеет 4 функции, соответствующие операциям;
- по нажатию кнопки выводит в окно результата значение;
- выводит сообщение об ошибке, если введены не числа.
2. Ход работы
2.1. HTML-структура
Создан файл `index.html` с контейнером `.calculator`, внутри:
- два инпута `input#num1` и `input#num2` (тип `text`, чтобы вручную проверять ввод);
- блок `.buttons` с четырьмя кнопками: «Сумма», «Разность», «Произведение», «Деление»;
- блок `div#result` для вывода результата или ошибки.
2.2. CSS-стилизация
В `style.css` реализовано:
- градиентный фон (`linear-gradient`);
- центрирование через `flex`;
- сетка кнопок через `grid` (2 колонки);
- стили для трёх состояний окна результата: обычное (нейтральное), `.error` (красное), `.success` (зелёное).
2.3. JavaScript-логика
В `script.js` реализовано:
- четыре функции: `sum`, `diff`, `mult`, `div` — каждая принимает два числа и возвращает результат;
- функция `parseNumber()` — проверяет, является ли введённое значение числом (`Number()`, `Number.isNaN()`), пустое поле или нечисло → возвращает `null`;
- функция `validateInputs()` — проверяет оба инпута, при ошибке вызывает `showError()`;
- функция `calculate()` — универсальная обёртка, принимает одну из функций операций, валидирует ввод, считает результат, отображает его;
- обработчики `addEventListener('click', ...)` на каждой кнопке;
- отдельная проверка деления на ноль: если делитель `0`, выводится ошибка «деление на ноль».
2.4. Обработка ошибок
Проверяются три случая:
1. Пустое поле — ошибка «введите числа».
2. Нечисловое значение (например, «abc») — та же ошибка (через `Number.isNaN`).
3. Деление на ноль — ошибка «деление на ноль».
3. Проверка работы
- Ввод `5` и `3` → «Сумма» = 8, «Разность» = 2, «Произведение» = 15, «Деление» ≈ 1.67.
- Ввод `abc` и `3` → ошибка «введите числа» при любой операции.
- Пустые поля → ошибка «введите числа».
- `5` и `0` → «Деление» → ошибка «деление на ноль».
