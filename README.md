Практика: Кейс-задача №4 — Интерактивный калькулятор
Описание проекта
Простой интерактивный калькулятор на HTML, CSS и ванильном JavaScript. Позволяет ввести два числа и выполнить одну из четырёх операций: сумму, разность, произведение, деление. Обрабатывает ошибки ввода (нечисловые значения, пустые поля, деление на ноль).
Технологии
- HTML5
- CSS3 (grid, градиенты, transitions)
- JavaScript (DOM, addEventListener, Number.isNaN)
Как запустить
1. Скачай файлы или склонируй репозиторий.
2. Открой `index.html` двойным кликом в браузере.
3. Введи два числа и нажми на кнопку с нужной операцией.
